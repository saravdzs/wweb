HTML
Lenguaje de Maracado de Hipertexto (Hypertext Markup Language),el codigo estándar que se utiliza para crear y estructurar la estrutura básica de cualquier paigna web
Etiqueta
Una etiqueta en html es un fragmento de código encerrado entre los simbolos de menor que y mayor que (< >) que sirve para indicar al navegador web cómo debe estructurar y mostrar el contenido de una página
Atributo
Los atributos de HTML son palabras especiales o valores adicionales que se colocan dentro de la etiqueta de apertura para configurar, modificar o controlar el comportamiento y la apariencia de un elemento
