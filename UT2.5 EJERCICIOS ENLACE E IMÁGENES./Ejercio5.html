Introducción

La informática es la ciencia y la técnica que estudia el tratamiento automático de la información mediante el uso de ordenadores y sistemas computacionales

HTML

HTML (por sus siglas en inglés, HyperText Markup Language, o Lenguaje de Marcado de Hipertexto) es el lenguaje estándar utilizado para crear y estructurar el contenido de las páginas web

CSS

CSS (siglas en inglés de Cascading Style Sheets, o Hojas de Estilo en Cascada) es un lenguaje de diseño gráfico que se utiliza para definir la apariencia visual de los documentos escritos en HTML o XML

Enlaces

En HTML, un enlace (o hipervínculo) es un elemento que conecta una página web con otra, con un archivo, con una sección específica de la misma página o con un recurso externo

Imágenes

En HTML, las imágenes se integran utilizando la etiqueta , que sirve para vincular un archivo gráfico (como JPG, PNG, GIF o SVG) dentro de una página web en lugar de insertarlo físicamente en el código. Es una etiqueta vacía que no requiere etiqueta de cierre
