Glosario de informática

HTML
HyperText Markup Language.
Lenguaje de marcas que define la estructura de las páginas web.
Navegador
Programa que interpreta documentos HTML y los muestra al usuario. Ejemplos:
  • Mozilla Firefox
  • Google Chrome
  • Microsoft Edge
Etiqueta
Tag
Marca que delimita un elemento. Puede ser:
  • De apertura: <p>
  • De cierre: </p>
  • Vacía: <br>
